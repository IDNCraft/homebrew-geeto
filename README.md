# Homebrew Tap for Geeto

AI-powered Git workflow automation CLI.

## Install

```bash
brew tap IDNCraft/geeto
brew install geeto
```

## Uninstall

```bash
brew uninstall geeto
brew untap IDNCraft/geeto
```
